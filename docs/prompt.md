## 1. 프로덕트 정의

AI 에이전트가 활성화될 때 화면에 나타나는 **비주얼 큐(AI Visual Cue)**의 물성·컬러·크기·모션을 디자이너가 조작하고, 그 결과를 **안드로이드 네이티브 코드로 내보내는 디자인 툴**.

- 툴 자체는 **브라우저에서 실행되는 웹앱**(HTML/CSS/JS 또는 React). 프리뷰 애니메이션은 웹에서 렌더링한다.
- 우측 Code 탭에는 현재 컨트롤 값이 반영된 **Kotlin + Jetpack Compose 코드**를 보여준다 (안드로이드에서 그대로 동작하는 것이 목표).
- 즉, "웹 프리뷰 ↔ Compose 코드"가 같은 파라미터로 동기화되는 구조가 핵심이다.

## 3. AI Visual Cue 사양

### 3-1. 기본 형태 & 인터랙션 (한 사이클)

1. 화면에 납작하게 붙어 있는 상태
2. 구(sphere) 형태로 떠올라 부유 (이때 살짝 그림자 생성)
3. 이동 후 다시 안착
4. 안착 지점에서 새 컴포넌트(리스트 등)가 생성됨

### 3-2. 레벨 전개 (첨부 Reference level 참고)

- Level 1: 화면 상단에 구가 생겨남
- Level 2: 구가 넓게 퍼지며 리스트 형태로 앱에 안착
- Level 3: 전체 화면으로 확산
- Level 1→2→3→1 을 무한 루프로 재생.
- 레벨 이미지 안의 세부 UI/텍스트는 무시. **기본 물성이 유지된 채 자연스럽게 퍼져서 안착되는 느낌**이 중요.
- 모션 타이밍/루프 방식은 첨부 Reference video를 따를 것.

### 3-3. 컨트롤 패널 항목 (Design 탭)

- **컬러**: 그라데이션 기본, 색상 스톱 최대 3개까지 추가/삭제/조절
- **물성(material)**: 첨부 Reference effect 이미지들을 기반으로 여러 타입 중 선택 (예: 글래스, 메탈, 소프트 글로우 등 — 첨부 이미지를 보고 타입명을 정의할 것)
- **크기**: 구 지름, 안착 시 높이/두께
- (가능하면) 모션 속도, 그림자 강도, 레벨별 지속 시간

## 4. 기술 요구

- 프리뷰: 웹 (Canvas/WebGL 또는 CSS 애니메이션 중 물성 표현에 적합한 것을 계획서에서 비교·선택)
- 출력 코드: **Kotlin + Jetpack Compose** (Android 최적). 셰이더가 필요하면 AGSL/RuntimeShader 등 Compose에서 실제 쓸 수 있는 방법만 제안할 것.
- 컨트롤 값 → 프리뷰, 컨트롤 값 → 코드가 하나의 상태(state)에서 파생되도록 설계

## 5. 첨부 자료 (이 프롬프트와 함께 제공)

- Reference video: 루프 모션 기준
- Reference effect: 물성 타입 기준 이미지들
- Reference level: Level 1/2/3 이미지
- App examples: 실제 앱 적용 모습
→ 계획서 각 Phase에서 어떤 자료를 어느 단계에 참조하는지 명시할 것.

## 6. 계획서 Phase 구성 가이드 (제안, 조정 가능)

- Phase 0: 요구사항 정리, 가정 확정, 기술 스택 비교·결정
- Phase 1: 레이아웃 뼈대 (탭바, 좌/우 분할, 다크모드, 프리뷰 3뷰 전환)
- Phase 2: 비주얼 큐 코어 모션 (납작→구→부유→안착→컴포넌트 생성, Level 1~3 루프)
- Phase 3: 컨트롤 패널 연결 (그라데이션 3스톱, 물성 타입, 크기)
- Phase 4: Compose 코드 생성기 + Code 탭
- Phase 5: 영상② 앱 적용 프리뷰, 폴리시, QA
